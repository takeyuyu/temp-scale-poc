# 気温 × 配管スケール堆積 PoC（合成データ）

「配管の詰まり方には季節がある」——現場で体感的に知られているこの経験則を、
ポンプ電流ログと気温データで定量化できるかを、合成データで検証する思考実験。

これは特定の企業・設備の話ではなく、スケールが溜まる一般的な設備を想定した
合成データによる検証です。実在の運転データは使用していません。

## 主な結果

- 生の日次データ（当日気温 vs 電流の日次変化）では相関がほぼ消える（r ≈ 0.0）
- 清掃サイクル単位（溜まりの速さ vs 「寒さの積み立て」）で見ると相関が立ち上がる（r = 0.63）
- 乱数シードを10通り変えても相関は 0.6〜0.85（平均 0.72）で安定

同じ一年のデータでも、**見る粒度を変えると季節の信号が戻ってくる**、というのが要点。

## 前提（6つ）

1. 液温は外気の影響を少なからず受ける（保温の有無を問わず季節では効く）
2. 溜まる向きは「冷えると速くなる」側（逆溶解度の物質では符号が反転する）
3. 原料・濃度は年間で大きく変わらない（四半期ごとのロット差は交絡として混入）
4. 電流は流量一定の条件で見る
5. 清掃のたびに堆積はリセットされる（ノコギリ波）
6. 薬注は検証期間中固定

結論ありきを避けるため、気温と無関係なノイズ（ロット差・運転ゆらぎ・測定ノイズ）を
意図的に混ぜた上で、それでも気温成分が取り出せるかを確認している。

## ファイル構成

```
scale_poc.py          合成データ生成 + サイクル相関の検証（本体）
make_figs.py          図の生成
verify.py             生成データと主張の整合チェック
scale_timeseries.csv  日次データ（生成済み）
scale_cycles.csv      清掃サイクル別の集計（生成済み）
fig1_before.png       生のポンプ電流と気温
fig2_after.png        寒さの積み立て vs 溜まりの速さ
fig3_contrast.png     両者の対比（記事の核）
```

## 再現手順

```bash
pip install numpy pandas matplotlib
python3 scale_poc.py     # データ生成・相関検証（CSVを再生成）
python3 make_figs.py     # 図を生成
python3 verify.py        # 主張とデータの整合を確認
```

## 注意

- 相関 0.63 は「強い」とまでは言えない。現実データではさらに濁りうる。
- 溜まる向きが逆の物質（温まると詰まるカルシウム系など）では符号が反転する。
  自分の現場がどちら向きかは、自分のデータで確かめること。
- これは合成データによる思考実験であり、実機での成立を保証するものではない。
